# recipe-app
App to help me learn claude code, create something practical, and get experience building websites

To put it online for your phone (free, password-protected), see [DEPLOY.md](DEPLOY.md).

## Start it with one click
Double-click the **Recipe App** shortcut on your Desktop (or in the Start menu).
It starts the app and opens http://localhost:5000 in your browser; a small
black window sits minimized in the taskbar while it runs, and closing it stops
the app. To pin it: right-click the Desktop shortcut, Show more options, Pin to taskbar.

If the shortcut is missing (new computer, moved the folder), make it again from
PowerShell in this folder: `powershell -ExecutionPolicy Bypass -File make_shortcut.ps1`
